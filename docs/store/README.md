# Paste vào App Store Connect

**Path:** App Store Connect → Apps → PTT Portal → App Store → App Review Information → Notes

**File copy:** [`app-review-notes-paste-en.txt`](./app-review-notes-paste-en.txt)

## Trước khi submit production

1. Thay `approver@demo.local` / `demo123` bằng **pilot approver thật** trên `portal.pttads.vn`
2. Xác nhận reviewer login được trên **TestFlight build** (không phải local stub)
3. Paste nội dung EN vào Notes + điền Sign-in required credentials

## Google Play

App content → App access → All functionality requires login → paste cùng đoạn EN + credentials.

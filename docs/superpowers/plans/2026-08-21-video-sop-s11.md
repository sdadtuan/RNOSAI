### Task 7: AssetDeliveryService

**Files:**
- Create: `adapters/asset-delivery.ts`
- Test: `adapters/asset-delivery.spec.ts`

**Interfaces:**

```ts
export type DeliverInput = {
  provider_code: VdProviderCode;
  role: 'start_frame' | 'end_frame' | 'reference' | 'source_video' | 'source_image';
  url?: string;
  buffer?: Buffer;
  contentType?: string;
};

export async function deliver(input: DeliverInput): Promise<{ ref: string; delivery: 'URL' | 'UPLOAD' | 'DATA_URI' }>
```

Rules S11 (mock, không S3 thật):
- `contentType` default `application/octet-stream` → ném `input_asset` nếu `provider_code==='runway'` (CT Runway).
- Runway: chỉ nhận `image/jpeg` `image/png` `image/webp`; trả `{ delivery: 'URL', ref }` với `Content-Type` giữ nguyên.
- Leonardo: `{ delivery: 'UPLOAD', ref: 'init-image://pending' }` (S12 gắn 2-step).
- Topaz image: `{ delivery: 'UPLOAD', ref: 'multipart://pending' }`.
- Kling/PiAPI: `{ delivery: 'URL', ref }` nếu url HTTPS.
- URL length > 2048 → `input_asset`.

- [ ] **Step 1:**

```ts
it('rejects runway octet-stream', async () => {
  await expect(
    deliver({ provider_code: 'runway', role: 'start_frame', url: 'https://cdn.example/a', contentType: 'application/octet-stream' }),
  ).rejects.toMatchObject({ error_class: 'input_asset' });
});
```

- [ ] **Step 2:** Implement. Commit: `feat(vd): S11 AssetDeliveryService content-type guards`

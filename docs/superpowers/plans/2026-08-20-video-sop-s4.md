## Global Constraints

- **Không** import `content-marketing/video-social/**`, `social-ffmpeg`, `social-video.service`, `content-media-image.provider`.
- **Không** job `social_*`. S4 image job chỉ `cine_keyframe` trên `q.image` (reuse S2 handler).
- **Không** set shot `keyframe_approved` (Gate 2 = S5). **Không** đổi project `stage` thành `animating`.
- Secret provider chỉ env. **Không** fake CDN URL ảnh (`url=''` khi chưa có storage).
- HTTP enqueue: `201 { id, status: 'queued' }`, header `Idempotency-Key` required.
- Caps: bible PUT = `crm_vd.bible` edit **or** `crm_vd.project` edit **or** `crm_content` write. Keyframe enqueue = `crm_vd.keyframe` edit **or** `crm_vd.project` edit **or** `crm_content` write.
- Flag cinematic bắt buộc (`assertCinematicEnabled`).
- **UI bắt buộc:** SC-05 + SC-06. Không ship S4 chỉ API.
- **Do not** run `export_rbac_admin_catalog.py`. Hand-add `crm_vd.bible` + `crm_vd.keyframe` to catalog + `admin_page_permissions.py`.
- Shot status on enqueue: `draft` → `prompts_ready` → `keyframe_pending`. Never `keyframe_approved` in S4.
- Lineage: on keyframe job **succeeded** with `shot_id`, insert `vd_asset_lineage` edge `prompt` (S4 stub: self-edge `parent_asset_id=child_asset_id=new asset id` for smoke — real parent chain in S5+).
- Import graph: `video-sop` ↛ `social-ffmpeg` / `social-video.service`. `social-studio.util` allowed.

# KPI Hub P2 — Implementation Plan (Governance + DQ + Live Data)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Out of scope P2 (→ P3):** Attribution Data-Driven, forecast nâng cao, Power BI refresh hai chiều, Slack/webhook, SSO/MFA, custom role, AI insight, composite expression tùy ý SQL.

## Global constraints (kéo từ P1)

- Dashboard **không** query Ads live theo request — chỉ đọc `crm_kpi_facts`.
- Ratio: `sum(num)/sum(den)`; blank-if-zero; không AVG tỷ lệ ngày.
- `DATA_ISSUE` precedence khi workspace bật + source Failed / DQ Critical.
- Optimistic lock `If-Match` → `409 KPI_HUB_VERSION_CONFLICT`.
- Không thay `/crm/kpi`, KPI Type, Nhóm KPI.
- CSS `.kpi-hub-*`, không Tailwind.

## P2-W1 — Fact compute & connectors

**Mục tiêu:** Materialize actual theo kỳ; CPL/MQL/Win tính từ dữ liệu thật (hoặc staging CRM/Meta đã có).

### Architecture

```text
Meta Ads / CRM Leads
        ↓
KpiHubConnectorPort (reuse kpi-types adapters)
        ↓
SourceBinding + MappingRules (SharePoint utm_campaign)
        ↓
FormulaEngine.compile(AST) → SQL/adapter query
        ↓
FactBatchService → UPSERT crm_kpi_facts
        ↓
Dashboard / Targets / Reports
```

| File | Vai trò |
|---|---|
| `kpi-hub/connectors/kpi-hub-connector.port.ts` | Interface query entity |
| `kpi-hub/connectors/crm-leads.connector.ts` | DISTINCTCOUNT lead_id |
| `kpi-hub/connectors/meta-ads.connector.ts` | SUM spend |
| `kpi-hub/facts/kpi-hub-facts.service.ts` | Batch compute (thay placeholder) |
| `kpi-hub/facts/kpi-hub-facts.repository.ts` | UPSERT fact |
| `kpi-hub/facts/kpi-hub-facts.scheduler.ts` | Cron daily 08:00 + after-sync hook |
| `kpi-hub/formula/kpi-hub-formula.compiler.ts` | AST → connector query |

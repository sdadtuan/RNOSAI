# CSD Chat P1.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đủ Chat MVP vận hành trên `/crm/csd/chat`: members, đóng/mở lại, reply, banner khách, AI summary trên panel phải — không omnichannel, không attach, không search.

**Architecture:** Mở rộng `CsdChatService` / repository trên bảng `csd_conversations` + `csd_conversation_members` + `csd_messages` đã có. Không bảng mới. ops-web chỉ sửa `CsdChatWorkspace` + `csd-api.ts`. AI summary gọi API `POST /api/crm/csd/ai/conversations/:id/summarize` đã ship.

**Tech Stack:** NestJS `ptt-crm-api` · Next.js ops-web · PostgreSQL `csd_*` · Jest · Playwright mock.

## Global Constraints

- Prefix `/api/crm/csd`. Cấm ghi `crm_tickets` / `ceo_command_turns`.
- Staff id = **INTEGER** JWT `staffId`. Member chỉ `member_type=staff` (client contact = P2).
- Client Chat: `visibility` luôn `client`. Copy UI tiếng Việt (UX §5, §9).
- Poll 5s giữ nguyên. Không WebSocket. Không `PTT_CSD_LLM=1`.
- Ticket từ tin: cùng tab, không `window.open`. Trùng source = ticket cũ.
- Out of scope P1.5: attach, search, pin, mention `@`, react, notify AM, keyword P1 gợi ý, mobile 2 màn, task engine.

**Interfaces:**

```ts
export type CsdConversationStatus = 'active' | 'archived' | 'closed' | 'reopened';

export type CsdConversationMemberRow = {
  conversation_id: string;
  member_type: 'staff';
  member_staff_id: number;
  role: 'owner' | 'member' | 'viewer';
  created_at: string;
};

export class CsdChatService {
  listMembers(actor, conversationId): Promise<{ items: CsdConversationMemberRow[] }>
  addMember(actor, conversationId, { member_staff_id, role? }): Promise<CsdConversationMemberRow>
  removeMember(actor, conversationId, memberStaffId): Promise<{ removed: true }>
  closeConversation(actor, conversationId): Promise<CsdConversationRow>
  reopenConversation(actor, conversationId): Promise<CsdConversationRow>
}
```

HTTP (guard `view` GET, `write` POST/DELETE):

```text
GET    /api/crm/csd/conversations/:id/members
POST   /api/crm/csd/conversations/:id/members
DELETE /api/crm/csd/conversations/:id/members/:staffId
POST   /api/crm/csd/conversations/:id/close
POST   /api/crm/csd/conversations/:id/reopen
```

Rules:
- `createConversation`: INSERT owner row `role=owner` (`member_staff_id=actor.staffId`).
- `kind=project` bắt buộc `project_ref_kind` + `project_ref_id` (BR-CHAT-01).
- `sendMessage` khi `status=closed` → `409 conversation_closed`.
- Close/reopen: `owner_staff_id === actor.staffId` **hoặc** cap `csd:manage` / `csd:admin`. Không thì `403`.
- Add member: `member_staff_id > 0`; unique staff; không add khi closed.
- Remove: không xóa owner.
